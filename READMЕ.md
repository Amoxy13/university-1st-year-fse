
 Задача А1. Тренажёр таблицы умножения

 Условие задачи
Напишите программу-тренажёр, которая запрашивает у пользователя количество примеров \(N\), после чего генерирует случайные математические выражения на умножение чисел в диапазоне от 2 до 9. 

Программа должна замерять время, потраченное пользователем на ответ, а также собирать итоговую статистику:
*   Общее время прохождения теста;
*   Среднее время, затраченное на один вопрос;
*   Количество и процент правильных ответов.

Программа должна быть устойчива к ошибкам ввода (например, если пользователь случайно ввёл букву вместо числа).

 Пример работы
```text
Введите количество примеров: 3
Вопрос 1/3
4 * 7 = 28
Верно! (Время: 2.3 сек)
Вопрос 2/3
9 * 6 = 52
Неверно! Правильно: 54 (Время: 4.1 сек)
Вопрос 3/3
3 * 8 = 24
Верно! (Время: 1.5 сек)

========================================
СТАТИСТИКА:
========================================
Общее время: 7.9 секунд
Среднее время на вопрос: 2.6 сек
Правильных ответов: 2/3
Процент правильных: 66.7%
```

 Задача А2. Отрисовка геометрических фигур

 Условие задачи
Напишите программу, которая принимает на вход два целых положительных числа: \(n\) (количество строк) и \(m\) (количество столбцов). Используя циклы, программа должна вывести на экран три геометрические фигуры, состоящие из символа решётки `#`:
1.  **Прямоугольник** размером \(n \times m\).
2.  **Правый треугольник** с высотой в \(n\) строк.
3.  **Пустую рамку** размером \(n \times m\) (символы `#` выводятся только по границам фигуры).

Программа должна корректно обрабатывать ошибочные размеры (ноль, отрицательные числа или нечисловой ввод).

 Пример работы для \(n=4, m=6\)
```text
ПРЯМОУГОЛЬНИК 4x6:
######
######
######
######

ПРАВЫЙ ТРЕУГОЛЬНИК:
#
##
###
####

РАМКА 4x6:
######
#    #
#    #
######
```

 Задача А3. Анализ сетевых пакетов

Условие задачи
Имитируется получение потока сетевых пакетов, представленных строкой из нулей и единиц (`1` — пакет доставлен успешно, `0` — пакет потерян). Программа принимает строку (длиной не менее 5 символов), выполняет валидацию ввода и рассчитывает метрики надёжности сети:
*   Общее число переданных пакетов;
*   Количество потерянных пакетов;
*   Длину самой протяжённой непрерывной серии потерянных пакетов (подряд идущие нули);
*   Процент потерь от общего трафика.

На основе процента потерь выводится вердикт о качестве связи:
*   \(\le 1\%\) — отличное качество;
*   \(\le 5\%\) — хорошее качество;
*   \(\le 10\%\) — удовлетворительное качество;
*   \(\le 20\%\) — плохое качество;
*   \(> 20\%\) — критическое состояние сети.

 Пример работы
```text
Ввод:
11100010111

Вывод:
Общее количество пакетов: 11
Количество потерянных пакетов: 4
Длина самой длинной последовательности потерянных пакетов: 3
Процент потерь: 36.4%
Качество связи: критическое состояние сети
```



## 💳 Задача А4. Валидатор номеров кредитных карт (Алгоритм Луна)

# Условие задачи
Реализуйте функцию `validate_card_number(card_number: str) -> bool`, которая проверяет корректность и подлинность номера банковской карты с помощью **алгоритма Луна** (Luhn algorithm). 

 Правила проверки:
1.  Из входной строки удаляются все посторонние разделители (пробелы, дефисы).
2.  Номер карты инвертируется (рассматривается справа налево).
3.  Цифры, находящиеся на чётных позициях (каждая вторая цифра), удваиваются. Если результат удвоения превышает `9`, из него вычитается `9`.
4.  Все цифры суммируются. Номер считается валидным, если итоговая контрольная сумма делится на `10` без остатка.

Пример работы
```text
Введите номер кредитной карты для проверки: 4992-7398-716
Вывод: Карта валидна (Номер корректен)

Введите номер кредитной карты для проверки: 4992-7398-717
Вывод: Карта невалидна (Ошибка в номере)
```
